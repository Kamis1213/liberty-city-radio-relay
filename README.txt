LIBERTY CITY RADIO RELAY v5.3 — AUDIO UPGRADE
=============================================

NEW IN v5.3
- More realistic fire-pager style two-tone dispatch alert
- Short transmitter key-up mic click/chirp
- Squelch-tail / mic-release click
- Cleaner channel-change chirp
- Revised emergency traffic alert cadence
- Sounds are generated by the RADIO SERVER web client, so installed Windows
  Radio v1.2 users do NOT need to reinstall the desktop app for these changes.

KEPT FROM v5.2
- Dispatch / Fireground 1 / Fireground 2 / Command channels
- Channel-isolated WebRTC voice traffic
- Callsign/channel roster
- Channel-busy protection
- Emergency button
- CAD /dispatch integration and spoken dispatch
- HTTPS microphone support

DEPLOY
------
1. Upload the CONTENTS of this folder to the SAME GitHub radio repository.
2. Replace the existing files and commit the changes.
3. Render redeploys automatically.
4. After Render is live, reopen/refresh the radio.
5. Click Enable Radio Audio and test a dispatch plus PTT.

CAD RADIO_API DOES NOT CHANGE:
https://liberty-city-radio-relay.onrender.com/dispatch
